Archivo informativo independiente. No se conecta con el sistema; sirve para abrirlo desde Android o computadora y entender que dependencias usa el proyecto.

Librerias cargadas en pantallas

Dependencias que aparecen en los archivos PHP o CSS del sistema.

Importación de archivos

Herramientas usadas por api/index.php para leer archivos antes de crear partes en lote.

Formato Herramienta Para que se utiliza
PNG / JPEG OCR.space API Extrae texto de imagenes mediante OCR usando OCR_SPACE_API_KEY.
PDF escaneado OCR.space API Lee PDFs que son imagenes escaneadas cuando no tienen texto digital.
PDF digital Smalot/PdfParser Extrae texto localmente desde PDFs con texto seleccionable.
Excel .xlsx/.xls PhpSpreadsheet Lee la plantilla de importación para previsualizar y crear partes.

Servicios externos usados por JavaScript

Servicios que se consultan desde el navegador cuando el usuario usa el mapa.

Servicio Donde se llama Para que se utiliza
Nominatim OpenStreetMap js/partes.js, funcion searchOpenStreetMap() Busca una direccion o kilometro escrito por el usuario y devuelve coordenadas.
Photon Komoot js/partes.js, funcion searchPhotonLocation() Buscador alternativo si Nominatim no encuentra resultado o falla.
OpenStreetMap Tiles L.tileLayer("https://{s}.tile.openstreetmap.org/...") Descarga las imagenes del mapa que se muestran dentro de Leaflet.

Nota de mantenimiento

Si una pantalla marca errores en consola por una libreria externa, revisar:

  1. Que haya internet.
  2. Que la URL del CDN siga activa.
  3. Que no haya atributos integrity desactualizados bloqueando el recurso.
  4. Que el orden de carga se mantenga: jQuery antes de Bootstrap, jQuery Easing y SB Admin 2.
